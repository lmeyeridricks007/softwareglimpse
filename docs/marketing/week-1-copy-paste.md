### Audio for this Reel (do this in the native app)

The file has **no soundtrack**. Attach audio **after** you import it. Use the **SoftwareGlimpse Business account** (not a personal login) so you only see tracks you are actually allowed to post.

**Use this one (first choice):** quiet lo-fi / documentary bed, **no vocals**, volume **12–18%**. It should feel like a calm explainer, not a trend.

In Instagram Reels → **Add audio** → search these exact phrases, in this order, until you get an instrumental result:

1. `lofi chill instrumental`
2. `calm documentary`
3. `soft piano ambient`
4. `corporate ambient` (skip anything with vocals, sax, or “success anthem” energy)

Pick a track **≥30 seconds**. Start it at **0:00** (downbeat on the hook slide). Fade is optional; a hard start is fine.

**If you add the voiceover below:** drop music to **6–10%** so speech leads.

**Do not use on this Reel** (wrong tone, and most are blocked on Business accounts anyway): Taylor Swift “august”, Noah Kahan “End of August”, Ian McConnell “You Never Take Me to Bangladesh”, phonk, “Oh No” (Kreepa), “It’s Corn”, She Wolf, Bad Bunny, dance sounds.

**Facebook:** same file → Reels composer → Meta Sound Collection → filter **Instrumental** → Calm / Documentary / Corporate. Same volume. If Business Suite strips the IG sound on cross-post, add audio again on Facebook or post the Reel natively on both.
