## Promotion and spend (read this once)

Social’s job is **tool starts**, not follower count. Promote the posts that send people into a Finder, calculator, or checklist. Do not pay to announce the brand.

### Gate (all four, or Spend = $0)

The 18 Aug 2026 site audit is **NOT_PUBLISHABLE** (legal identity empty). Until that is real:

| Allowed | Not allowed |
| --- | --- |
| Organic posts, Stories, highlights, FB pin, first-comment URLs | Boosts, Ads Manager, lead ads, “Advertise” on the Page |
| “Rebuilding in public” | “We’re live / launch day” as a paid campaign |
| `/resources/` as the download | Email lead ads (newsletter still unconfigured) |

After legal identity is live, paid still waits until **one** of these is true:

1. Four weeks of organic Meta data exist, **or**
2. One tool Reel already has **≥20 Facebook link clicks** (or clear IG profile visits → bio).

Then you may spend the amounts in the tables. Those numbers are **caps**, not targets. If the post is dead after 24 hours, do not boost it.

### What “Promote” means

Do this the same way every time. Skip any step the table does not ask for.

| Code | Do this |
| --- | --- |
| **Stories** | Within 2 hours: share the post to IG + FB Stories. FB: link sticker to the same URL + UTM. IG: link sticker if the account has it; otherwise “link in bio → Tools.” |
| **Comment** | IG first comment = full URL (`utm_source=instagram`). FB already has the URL in the caption. |
| **Highlight** | Add the last Story frame (or the Reel cover) to the matching IG highlight: Tools · CRM · Sales intel · Resources. |
| **Pin** | Pin on the Facebook Page for **7 days**. Unpin the previous pin. Never pin pre-rebuild posts. |
| **Boost** | Paid, only if the Spend cell is not `$0` **and** the gate is open. Setup below. |
| **Never** | Do not boost this creative later either (founder-launch talk, holiday filler, affiliate-optics posts). |
| **—** | Publish and stop. No extra Stories push. |

Default for every Thursday Reel and every Sunday tool/resource: **Stories + Comment**. The table only repeats that when it also adds Highlight, Pin, or Boost.

### What we pay for (and what we never pay for)

**Pay (after gate):** screen-recorded **tool Reels** and **cost/TCO** carousels whose destination is a live Finder, calculator, scorecard, demo checklist, or RFP builder.

**Organic only:** named-product Saturdays, comparisons, founder/methodology, “best of” trophies, partial tools you have to caveat, Christmas week.

**Never boost**

- “We rebuilt / we’re live / launch week” as the message (boost the **Finder demo** that week instead)
- Affiliate-disclosure Reels
- How-we-review / methodology carousels
- Any URL you have not opened this week
- Engagement bait, lead ads, or a boost that lands on the homepage

### How to run a boost

1. Wait **24 hours** of organic. Boost only if the URL works, comments are not angry, and the post got *some* reach.
2. Prefer **Ads Manager → Traffic → Landing page views** to the **same destination** as the post. If that is too heavy, native **Boost post** with objective **Traffic** (not Reach, not Engagement).
3. Do not use the Page’s yellow **Advertise** button on a random post.
4. Paid UTM (replace organic `social`):

```text
?utm_source=facebook&utm_medium=paid_social&utm_campaign=sg_meta_2026h2&utm_content=boost_{slug}
```

Instagram paid: `utm_source=instagram` + same campaign/content.

5. **Audience (tests):** US + UK + AU, ages 25–54, English. Interests only if the pixel is empty: CRM software, HubSpot, Salesforce, B2B sales. **After 100 site visitors:** 1% lookalike of visitors + retarget 30-day visitors (exclude 7-day converters when you can measure tool starts).
6. **Placements:** Facebook Feed, Facebook Reels, Instagram Feed, Instagram Reels. **Off:** Audience Network, Messenger, in-stream/partner.
7. **Creative:** the tool Reel (or the cost carousel). Destination is the tool, not `/`.
8. **Kill after ~$40 spent** if any of these: CTR &lt; 0.6%, ≥$2.50 per landing-page view, zero landing-page views, frequency &gt; 3 in 7 days with no clicks. Do not “give it another week.”
9. **Scale:** only a creative that already produced **tool starts** (or, until analytics is live, repeat landing-page views at ≤$1.50). Raise to **$20–30/day**. Do not run more than **two** paid creatives at once.
