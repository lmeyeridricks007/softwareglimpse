## 4. Images: highlight covers

Instagram draws a **circle** over these squares. Icons sit in the middle; the **name under the circle** is what you type in the app (Tools, CRM, …). Ignore any small word baked into the PNG.

| File | Highlight name | Add after |
| --- | --- | --- |
| `highlight-tools.png` | **Tools** | Fri Stories (or Sun, when you share the tools carousel to Stories) |
| `highlight-crm.png` | **CRM** | Sat carousel shared to Stories |
| `highlight-my-story.png` | **My Story** | Thu Reel shared to Stories, or Wed Stories |
| `highlight-resources.png` | **Resources** | First resource/checklist Story (Week 2 Sun is fine) |
| `highlight-sales-intel.png` | **Sales intel** | November SI week — create the cover now, or wait |

**Left-to-right order** (drag to reorder): Tools → CRM → Sales intel → My Story → Resources.

Skip a highlight until you have at least one Story in it. Empty highlights look unfinished. Week 1 you only **need** Tools + My Story; add CRM on Saturday.

### How to create one highlight

1. Publish the Story (or share the feed post / Reel **to Story**).
2. Profile → **+ New** under the photo (Highlights).
3. Select those Story frames → **Next**.
4. Highlight name = the table above (exact spelling).
5. **Edit cover** → **Gallery** → pick the matching `highlight-*.png` from Camera Roll.
6. Zoom so the icon sits in the **center** of the circle. Save.

Do **not** name a highlight “How we review”. That pillar is out.

## 5. Grid, pins, old posts

Instagram shows **newest first**, left to right, three columns. After Week 1 Sunday the top row should be:

| Left | Middle | Right |
| --- | --- | --- |
| Sun tools carousel | Sat “best for this team” | Thu Reel |

That row is `grid-week-1-preview.png`. If it isn’t, you posted in the wrong order or included Tuesday (skip Tuesday).

**Pin (after Sunday exists):** Profile → post → **…** → **Pin to profile**. Pin **three**, in this order:

1. Sunday tools carousel  
2. Saturday CRM carousel  
3. Thursday Reel  

Pins stay at the top when newer posts land. Unpin later only to replace with a stronger tool Reel.

**Old grid posts** (lifestyle, hotel CRM, Fastmail, etc.): leave them. They drop below. Do not archive everything this week unless you want a blank grid — then archive *before* Week 1 so the first row is only new work.

**Reels tab:** the Thursday file lives there automatically. Do not also post it as a static feed image.
