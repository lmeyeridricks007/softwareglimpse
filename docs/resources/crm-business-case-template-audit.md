## What is conceptually wrong

A **business case** should help a buyer turn a CRM problem into a financially and operationally credible proposal for sponsor/leadership approval.

The generated PDF/Excel are dominated by **evaluation-checklist UX**:

- Numbered check items
- Pass / Partial / Fail / Not tested
- Evidence boxes per row
- Must-have (`*`) markers
- “Completion guidance” boxes copied from checklist resources

That interaction model belongs on Evaluation Checklist, Vendor Scorecard, Requirements validation — **not** as the core of a business case.

The hub profile also frames the artifact as a **one-page memo checklist** (ask-block gates, PASS/PARTIAL/FAIL worked example for options) rather than a working financial/operational workbook (current-state cost → options → TCO → benefits → ROI → risks → recommendation → decision).

## Checklist reuse (shared pipeline)

`export-documents.ts` applies the same layout to every resource:

1. Header + how-to steps from `workflowSteps`
2. Hardcoded key: Pass / Partial / Fail / Not tested | * = Must-have
3. Table: # | Check item | Why it matters | REQ | Evidence | Result
4. Rows from `profile.artifactSections[].items`
5. Excel: Result key + Checklist sheet + Summary counts of Pass/Partial/Fail

Business-case `artifactSections` were authored to feed that table (labels like “Single decision requested…”, `required: true`, `testScenario`, etc.), so the content itself was shaped as checks.

Pass/Fail also appears in:

- `workedExampleStructured.vendors[].result` (schema forces PASS|PARTIAL|FAIL|NOT_TESTED)
- `ResourceArtifactPreview` column headers (“Check item”, “Result”)
- Cross-cutting notes in `docs/content-ecosystem/resources/RESOURCE-AUDIT.md` that still push Pass/Fail into downloads globally

| Worked example | Structure/options narrative — drop PASS/FAIL vendor cards |
| Seed SEO + short descriptions | Approval-ready case language |
| Catalogue notes | Correct purpose near approval stage in journey |
| Preview visuals (optional follow-up) | Align hero/needs/workflow PNGs to new flow: Current state → Investment → Benefits → ROI → Recommendation → Approval |
