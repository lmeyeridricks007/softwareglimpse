## Why it behaves like a checklist

1. **Shared PDF/XLSX renderer** always prints Pass / Partial / Fail / Not tested and a single-vendor-style evidence column layout (or vendor A/B/C comparison sheets that still look like checklists).
2. **Profile copy** was rewritten as “gates-only decision page” and still uses Pass/Fail language in hero, worked examples, and artifact rows — so content was shaped to feed the checklist table.
3. **Primary CTA ordering** puts Excel first for worksheets, but Excel content is still Instructions + Checklist-style sheets, not a weighted decision engine.
4. **No archetype routing** except the business-case slug branch — Decision Matrix falls through to the generic path.

A true decision matrix must compare **multiple finalists** with:

- Must-have gates (PASS / FAIL / UNKNOWN — not averaged)
- Weighted criteria (1–5 × weight → /100)
- Evidence confidence
- Cost / TCO
- Risk
- Sensitivity
- Recommendation

## What must change

| Layer | Replace with |
| --- | --- |
| PDF | ~10-page executive decision summary: overview → framework → gates → weights → scoring → category compare → cost → risk/confidence → results → recommendation |
| Excel | Interactive engine sheets `00_READ_ME` … `10_RECOMMENDATION` with formulas (gates, weights=100%, weighted fit, TCO, sensitivity) — blank / SAMPLE only |
| Markdown | Decision-matrix narrative (not checklist rows) |
| Hub profile | Multi-vendor decision language; Excel primary CTA |
| Preview UI | `decision-matrix` variant (no Pass/Fail table) |
| Archetype docs | Document DECISION_MATRIX vs CHECKLIST / SCORECARD / BUSINESS_CASE |
| Seed SEO | Shortlist comparison + weighted decision wording |

**Do not invent** vendor scores, prices, TCO figures, or evidence. SAMPLE weights must be labelled as samples.

---

## Differentiation vs Vendor Scorecard

| | Vendor Scorecard | Decision Matrix |
| --- | --- | --- |
| Question | How well did **this** vendor perform in evaluation? | Which **finalist** should we select? |
| Shape | Deep per-vendor evidence | Cross-vendor gates + weights + cost + risk |
| Output | Evaluation record | Decision + recommendation |
